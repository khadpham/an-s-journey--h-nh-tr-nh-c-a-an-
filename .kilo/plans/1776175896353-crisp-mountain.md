# Plan: GameBalls "Tricky" Mechanism

## Problem Statement
Players can get "lucky" in Game 8 (Balls) by guessing. Currently:
- Fake ball position and heavy/light is randomized at game start
- A smart player using 4v4 first weighing, if balanced, immediately narrows down to 4 balls (easy case)
- This allows winning in fewer than 3 weighings by luck

## Goal
Implement "Cat-like" behavior - make the puzzle ALWAYS adapt to be as hard as possible, never allowing lucky wins.

## Concept: "Adaptive Fake Ball"
The fake ball's behavior adapts AFTER the player places balls but BEFORE the weighing result is shown. This is similar to how the Cat moves AFTER the player checks a box.

## Implementation Plan

### Algorithm: "Hardest Path Guarantee"

1. **When player initiates a weighing** (after placing balls on both pans):
   - Calculate what result the CURRENT config would produce
   - If the result would be "too easy" (e.g., balanced with 4v4, narrowing to just 4 balls), ADAPT the config

2. **Adaptation Rules** (Priority-based):
   - **Rule 1**: If 4v4 and result would be "balanced" → Change fake ball to be one of the 8 ON the scale
     - This forces the player to work with 8 balls in remaining 2 weighings (harder)
   - **Rule 2**: If 3v3 and result would be "balanced" → Change fake ball to be one of the 6 ON the scale
   - **Rule 3**: For any configuration, if the resulting state would give the player too much information (making the puzzle solvable in <3 weighings), adjust

3. **The "Cat Logic"**:
   - The Cat in Game 4 moves AFTER you check, making it hard to corner
   - The Fake Ball in GameBalls "adapts" AFTER you place balls but BEFORE you see result
   - Both try to maximize survival/difficulty

### Detailed Algorithm for Weighing 1

```
Given: player places X balls on left, Y balls on right

1. Calculate what result (left vs right) current config would produce
2. Determine "ease score" of that result:
   - Balanced with X=Y=4 → Ease = HIGH (only 4 candidates remain)
   - Balanced with X=Y=3 → Ease = MEDIUM (only 6 candidates remain)
   - Unbalanced → Ease = LOW (8 candidates, need to analyze which side)
3. If Ease > threshold (configurable, suggest 2):
   - Find a ball ON the scale that can be made the fake ball
   - Adjust weight (heavy/light) to make the result unbalanced
   - This ensures player always faces a harder puzzle
```

### Code Changes

**File**: `features/games/balls/GameBalls.tsx`

1. Add `adaptConfig` function that analyzes player's weighing and adjusts fake ball if needed

2. Modify `weigh()` function:
   - Call `adaptConfig` before calculating result
   - This ensures the result is always "optimal difficulty"

3. Add helper functions:
   - `calculateWeighCandidates()`: Given a result, return which balls could be fake
   - `isTooEasy()`: Check if current result gives player too much info
   - `adaptFakeBall()`: Swap fake ball position/weight to make it harder

### Example Scenario (4v4)

**Before adaptation:**
- Player places [1,2,3,4] vs [5,6,7,8]
- Fake ball is #9 (off-scale) - weight normal
- Result: BALANCED (because #9 not on scale)
- Player now knows fake is among [9,10,11,12] - TOO EASY!

**After adaptation:**
- System detects: 4v4 would be balanced → TOO EASY
- System swaps fake to #1 (which IS on the scale)
- Adjusts weight to make it balanced-ish but not quite...
- Result: SLIGHTLY UNBALANCED (left heavier or right heavier)
- Player must now analyze 8 balls, not 4 - HARDER!

### Why This Is Fair
- The player makes their choice (which balls to put on each pan)
- The puzzle then responds to that choice (like the Cat)
- The player can still WIN by being skillful in subsequent weighings
- But they can't get "lucky" with an easy first result

### Alternative Simpler Approach
Instead of full adaptation, use "Pre-Generated Hard Puzzles":
- Generate puzzle configs that GUARANTEE the first weighing is never "easy"
- Only use puzzle configurations where 4v4 always produces unbalanced result
- This is simpler but less flexible (only works for 4v4 first weighing)

### Recommendation
Implement the **Adaptive Fake Ball** approach because:
1. It works for ANY first weighing choice (not just 4v4)
2. It truly mirrors the Cat's intelligent behavior
3. It ensures maximum difficulty regardless of player strategy
